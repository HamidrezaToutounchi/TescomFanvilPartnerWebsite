# Fanvil & LINKVIL Türkiye Gold Partner Portalı (Tescom Fanvil Partner Website)

Fanvil ve LINKVIL kurumsal ses ve görüntü (A&V-IoT) çözümleri için modern, sade ve tüm cihazlara (mobil, tablet, masaüstü) %100 uyumlu kurumsal çözüm, ürün kataloğu ve Gold Partner portalı.

## Özellikler
- **Resmi Fanvil & Fanvil Gold Partner Kimliği**: Vektörel ve resmi logolar, Gold Partner güvence rozetleri.
- **5 Sütunlu Mega Menü & Mobil Çekmece Menü**: Kurumsal SIP Telefonlar, Otel & 2-Wire Çözümleri, LINKVIL Kablosuz UC & Kulaklık, SIP Güvenlik/İnterkom/Sağlık, SIP Hoparlör/Paging/Gateway.
- **Eksiksiz Ürün Kataloğu (120+ Model / 50 Ürün Grubu)**: V Serisi, A Serisi Konsol, X/XU Serisi, X300 Serisi, H600/H Otel Serisi, 2-Wire PoE Switch & Telefonlar, LINKVIL Wi-Fi/DECT/Konferans, i6 Kapı İnterkomları, i500 İç İstasyonlar, Y501 Hemşire Çağrı, SIP Hoparlörler, Gateway ve FDMS/FCMS/FNCS.
- **Dinamik Filtreleme & Yan Yana Model Karşılaştırma**: 15 ürün serisi, teknik etiket filtreleri, anlık arama ve mobil/masaüstü uyumlu 4'lü model karşılaştırma motoru.
- **B2B Proje Teklif Sepeti & Ürün Bilgi Formu**: Ürünler hakkında bilgi alma, FPRS proje kaydı, alt bayilik başvurusu ve 2-Wire demo talep formu.

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```

Üretim (Production) derlemesi için:

```bash
npm run build
```
